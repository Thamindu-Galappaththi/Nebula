┌─────────────────────────────────────────────────────────────────┐
│ 🆘 EMERGENCY: Everything is Broken!                             │
└─────────────────────────────────────────────────────────────────┘

STEP 1: Put in maintenance mode
   php artisan down

STEP 2: Clear everything
   php artisan cache:clear
   php artisan config:clear
   php artisan route:clear
   php artisan view:clear

STEP 3: Check .env
   APP_DEBUG=false
   APP_ENV=production

STEP 4: Rebuild caches
   php artisan config:cache
   php artisan route:cache

STEP 5: Bring back online
   php artisan up

STEP 6: Test /diagnostics

If still broken:
   • Check storage/logs/laravel.log
   • Temporarily set APP_DEBUG=true to see errors
   • Comment out CSP middleware as last resort

┌─────────────────────────────────────────────────────────────────┐
│ 📞 USER SUPPORT SCRIPT                                          │
└─────────────────────────────────────────────────────────────────┘

When user reports an issue:

YOU: "Let's try a few quick fixes first:"

1. "Please hard-refresh the page: Press Ctrl+Shift+R"
   → Wait for response

2. "Please clear your browser cache:
    • Press Ctrl+Shift+Delete
    • Check 'Cached images and files'
    • Click 'Clear data'"
   → Wait for response

3. "Please try opening the page in Incognito/Private mode"
   → If it works in incognito = cache issue

4. "Please press F12, click the Console tab,
    and tell me if you see any red error messages"
   → Screenshot these!

5. "What browser and version are you using?"
   → Chrome 120? Firefox 115? etc.

Then escalate with:
   • Screenshots of console errors
   • Browser and version
   • Exact steps to reproduce
   • User role
   • Time of occurrence
