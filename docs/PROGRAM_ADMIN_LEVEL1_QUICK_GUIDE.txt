🚀 HOW TO USE
══════════════════════════════════════════════════════════════════════════

STEP 1: Login
  • Login as Program Administrator (level 01) user
  • If testing as Developer/Admin, note the warning banner

STEP 2: Access Tool
  • Visit: /permission-checker
  • You'll see all 29 permissions organized by category

STEP 3: Run Tests

  OPTION A - Test One at a Time:
    • Click "Test" button next to any permission
    • Wait for result (green = pass, red = fail)
    
  OPTION B - Test All Permissions:
    • Click "Run All Tests" button at top-right
    • Wait ~15 seconds for completion
    • Review summary statistics

STEP 4: Review Results
  • Green cards with ✓ = Working correctly
  • Red cards with ✗ = Has issues
  • Check error messages for details

STEP 5: Export Results
  • Click "Export Test Results" for JSON file
  • Click "Print Report" for PDF/printout

══════════════════════════════════════════════════════════════════════════
🔍 INTERPRETING RESULTS
══════════════════════════════════════════════════════════════════════════

✅ PASSED (Green)
  • HTTP 200: Page loads successfully
  • Permission is working correctly
  • No action needed

❌ FAILED (Red)
  • HTTP 404: Route not found
    → Check routes/web.php for missing route
    → Verify URL mapping
    
  • HTTP 403: Access denied
    → Check middleware configuration
    → Verify role name spelling
    → Check RoleHelper.php permissions
    
  • HTTP 500: Server error
    → Check storage/logs/laravel.log
    → Fix PHP errors in controller/view
    
  • Timeout: Page too slow
    → Optimize database queries
    → Check for missing indexes

🛠️ TROUBLESHOOTING
══════════════════════════════════════════════════════════════════════════

Problem: Tool shows wrong role warning
Fix: Login with correct role or ignore if testing as Developer

Problem: All tests fail with 419 errors
Fix: CSRF token issue - refresh page and try again

Problem: Tests hang/freeze
Fix: Check for slow database queries, add indexes

Problem: Can't access /permission-checker
Fix: 
  • Check you're logged in
  • Verify your role has access
  • Clear route cache: php artisan route:clear

Problem: Results don't match manual testing
Fix:
  • Clear browser cache
  • Try incognito mode
  • Check for JavaScript errors (F12)
